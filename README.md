# 에피브리프 (EpiBrief)

공식 소스를 고르면 → 자료를 담고 → 서식에 맞춰 뉴스레터를 만들어 주는 도구입니다.
서버가 필요 없습니다. GitHub Pages에 그대로 올라갑니다.

- 화면: `index.html`
- 소스 목록: `data/sources.json`
- 자동 수집분: `data/feed.json` (GitHub Actions가 매일 KST 05:00 갱신)
- 수집 스크립트: `scripts/build_outbreak_feed.py`
- 자동화: `.github/workflows/newsletter.yml`

## 화면 구성 (2026.09 개편)

| 주소 | 하는 일 |
|---|---|
| `/` | 새 제작 화면. 홈 → **예시 선택 → 내용 바꾸기 → 확인하고 내보내기** 3단계 |
| `/brief.html` | 전 버전 전문 브리프 제작 도구(공개 소스 선택·AI 초안). 「더 보기 → 고급 도구」에서 연결 |
| `/local/` | 지자체 소식지 + 기관 공동 저장(비밀번호·버전 충돌·백업) |
| `/issues/` | 발간한 뉴스레터 목록 |
| `/subscribe.html` | 구독 신청 안내 |

### 새 제작 화면의 예시 6종
우리 동네 건강소식(보건소·지자체) · 감염병 사회 대응 PHSM 브리프(전문가) · 감염병·보건 동향(실무자) ·
캠퍼스 건강레터(대학) · 병원 건강레터(환자·보호자) · 연구·기관 소식(대학·병원·학회).
예시 카드의 미리보기는 편집기·내보내기와 **같은 렌더러**(`assets/render.js`)로 그립니다.

### 파일
- `assets/templates.js` 예시 6종 정의
- `assets/render.js` 소식지 렌더러 — 미리보기 · 예시 카드 · 단일 HTML 내보내기
- `assets/app.js` 화면 로직(라우팅·편집·저장·내보내기), `assets/app.css` 도구 서식
- `paper.css` 발간 서식(도구와 발간본이 함께 씀), `email.js` 메일 본문 변환

### 하지 않는 것
조회수·구독자 수·절약 시간 같은 실적을 만들지 않습니다. 내보내기는 파일을 만드는 것까지이며
발송·게시 완료로 표시하지 않습니다. PDF는 브라우저 인쇄로 저장하며 도구가 직접 만들지 않습니다.
게시 링크 복사는 실제 게시 주소를 넣었을 때만 켜집니다.

유형마다 본문 소제목과 AI 문체가 달라집니다.

- 발생동향: 발생 상황 / 상황 평가 / 국내 관련성·권고
- 사회대응: 연구·정책 동향 / 핵심 쟁점과 근거 / 분과위 시사점·토론거리
- 만성질환: 주요 동향 / 근거 해석 / 국내 적용 시사점
- 기후·건강: 기후·건강 동향 / 감시체계와 근거 / 국내 대응 시사점

기본 소스는 **78곳**이 미리 들어 있습니다(기관 발표·뉴스 검색·논문 검색).
②단계 상단의 **주제 칩**(폭염, 뎅기, 백신 수용성, 암 검진 …)을 누르면 그 주제 자료만 걸러 봅니다.

## 구독 신청

`subscribe.html` — 뉴스레터 하단의 **구독 QR과 '이 뉴스레터 받아보기'** 가 이 화면으로 이어집니다.
`?series=phsm` 처럼 열면 해당 뉴스레터가 미리 선택됩니다.

접수 방법은 `subscribe-config.json` 으로 정합니다.

```jsonc
{ "email": "newsletter@korea.kr",   // 신청 메일을 받을 주소 (서버 없이 동작)
  "formUrl": "",                    // 구글폼 등 양식이 있으면 그 주소 (email 보다 우선)
  "org": "질병관리청" }
```

구독 화면 아래 **담당자 설정**에서 입력하고 `설정 파일 내려받기` → 이 파일을 교체하면 모든 방문자에게 적용됩니다.
설정 전에는 신청 내용을 복사해 담당자에게 보내는 방식으로 동작합니다.

## 화면 구성 (메뉴 4개)

| 메뉴 | 하는 일 |
|---|---|
| **홈** | 플랫폼 소개·사용법 4단계 + 최신 뉴스레터 목록(열기 / 발행 / 이 서식으로 새 호 만들기) |
| **최신 뉴스레터** | 발간한 호 전체 목록과 발행 방법 선택 |
| **맞춤형 제작** | ① 소스 선택 → ② 자료 담기 → ③ 서식·발행 정보 → ④ 미리보기·발행 |
| **My Newsletter** | 내가 만든 뉴스레터 보관함(열어서 고치기 / 메일 복사 / HTML 저장 / 삭제) |

구독 QR은 **그 뉴스레터 시리즈만 모아 보는 주소**(`issues/?series=phsm`)로 만들어지며,
창간호는 "이 뉴스레터 구독 안내", 2호부터는 "구독 · 지난 호 보기"로 문구가 바뀝니다.

## 쓰는 순서

1. **소스 고르기** — 유형을 고르고, 기관을 체크하고, 기간(7~45일)을 정합니다.
2. **자료 담기** — 목록에서 `담기`. 원하는 글은 URL을 넣어 직접 담을 수도 있습니다.
   `주제 자동 묶기`를 누르면 병명·주제별로 자동 분류됩니다(직접 고칠 수 있음).
3. **초안 만들기** — 발행 정보(기관·호수·발행일)를 적고 서식 3종 중 하나를 고른 뒤 `초안 만들기`.
   - Claude API 키를 넣으면 AI가 요약·평가·시사점까지 정리합니다(키는 이 브라우저에만 저장).
   - 키가 없으면 `AI 없이 기본 초안`으로 뼈대와 출처가 자동 정리됩니다.
4. **다듬고 내보내기** — 미리보기 글자를 직접 고친 뒤 인쇄·PDF / HTML / 이메일 본문 / 워드로 내보냅니다.

## 이번 개편 (읽기 · 공유)

- **3초 브리핑 구조**: 제호 → 한 줄 리드 → 지표 4개 → 이번 호 한눈에 보기(주제·요지·성격 태그) → 본문
- **분야별 색**: 감염병 남색+오렌지 / 사회대응 인디고+청록 / 만성질환 딥그린+앰버 / 기후 벽돌+하늘
  (모두 흰 바탕 명암비 4.5:1 이상, 색과 함께 항상 글자 라벨을 둡니다)
- **액자 테두리**와 큰 본문(17px), 숫자 굵게·근거번호 위첨자
- **발간본 상단 네비**: 에피브리프 / 발간 목록 / 다른 호 이동 / 인쇄 / 이메일
- **이메일로 바로 보내기**: 메일 본문 복사(서식 유지) · 메일 프로그램 열기 · 메일용 HTML 저장
  (`email.js` — 표 구조 + 인라인 서식으로 다시 그립니다)
- **구독 QR**: 발행 시 구독 링크를 QR 그림으로 만들어 종이·메일에 함께 넣습니다
- **키워드 보고서**: ②단계에서 키워드를 넣으면 기본 소스 전체에서 관련 자료를 모아 초안까지 생성
- **공유 링크**: 보고서를 주소 한 줄에 담아 전달(받는 사람은 링크만 열면 같은 보고서를 봅니다)

## 소스가 어디서 온 것인지

소스 카드마다 이렇게 표시됩니다.

- **한 줄 설명** — 이 기관이 무엇을 주는 곳인지
- **수집 방식 배지** — `기관 RSS`(기관이 직접 내보내는 목록) / `뉴스 검색`(RSS가 막혔거나 없는 곳은 뉴스 검색으로 대체) / `논문 검색`(Europe PMC)
- **최근 건수** — 마지막 자동 수집에서 몇 건을 가져왔는지
- **기관 사이트** 링크

목록의 각 글에도 기관명·저널/언론사·원문 도메인·날짜가 함께 붙습니다.

## 소스를 더 넣고 싶을 때

### 화면에서 바로 (내 소스)

목록에 없는 기관이 필요할 때만 ①단계 아래 **소스 직접 추가**를 펼쳐 이름과 다음 중 하나를 넣습니다.

- 기관 RSS 주소 — 예: `https://www.cidrap.umn.edu/rss.xml`
- 뉴스 검색어 — 예: `Japan measles outbreak`
- 논문 검색어(Europe PMC) — 예: `("mask mandate") AND (SRC:MED OR SRC:PPR)`

`추가한 소스 지금 가져오기`를 누르면 브라우저에서 바로 불러옵니다(막히면 읽기 도우미를 거칩니다).
추가한 소스는 이 브라우저에 저장되며, **매일 자동 수집**까지 시키려면
`소스 설정 파일 내려받기`로 받은 `groups` 내용을 아래 파일에 넣으면 됩니다.

### 저장소 설정에 넣기

`data/sources.json` 의 `groups` 에 추가합니다.

```jsonc
{ "id": "새소스id", "name": "화면에 보일 이름", "region": "유럽",
  "rss":   "https://example.org/feed.xml",       // ① 기관 RSS
  "query": "검색어",                              // ② RSS가 막히면 뉴스 검색으로 대체
  "epmc":  "(\"검색어\") AND (SRC:MED OR SRC:PPR)", // ③ 논문(Europe PMC) 검색
  "filter": ["키워드"],                           // (선택) 이 단어가 있는 글만
  "site": "https://example.org/", "lang": "en",
  "desc": "이 기관이 무엇을 주는 곳인지 한 줄 설명" }
```

그룹의 `kind` 값(`outbreak` / `phsm` / `chronic`)이 어느 뉴스레터에 나타날지를 정합니다.

## 저작권 메모

제목·출처·날짜·링크와 짧은 발췌만 저장합니다. 원문 전체는 저장하지 않으며,
뉴스레터에는 항상 원문 링크가 각주로 붙습니다.

## 메일 발송 서비스(스티비)로 보내기

에피브리프는 메일을 직접 보내지 않습니다. 발송은 스티비 같은 서비스에 맡깁니다.

1. ④ 단계에서 **스티비용 HTML 복사** (지역 소식지 화면도 같은 버튼이 있습니다)
2. 스티비 → 이메일 만들기 → 콘텐츠 → **HTML 가져오기** → 붙여넣기
3. 스티비에서 구독자 그룹을 골라 발송

- 스티비 무료 플랜(구독자 500명, 월 2회)에는 HTML 가져오기가 없습니다. 그때는 **본문 복사해서 붙여넣기**로 스티비 에디터에 붙입니다.
- 구독 신청도 스티비 구독 페이지로 받으려면 `subscribe-config.json`의 `formUrl`에 스티비 구독 페이지 주소를 넣습니다.
