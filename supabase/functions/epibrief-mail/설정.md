# 자동 회신 메일 켜는 법 (Resend)

신청 화면(`/apply.html`)과 관리 화면(`/admin/`)은 이미 이 함수를 부르고 있습니다.
**열쇠 네 개만 넣으면** 그때부터 메일이 나갑니다. 넣기 전에는 지금까지처럼 접수만 되고 메일은 나가지 않습니다
(메일 때문에 신청이 실패하는 일은 없습니다).

## 1. Resend 가입과 도메인 등록

resend.com 가입 → **Domains → Add Domain** → 쓰실 도메인 입력 (예: `jieumworks.com`)

화면에 DNS 세 줄이 나옵니다. 도메인 산 곳(가비아·카페24·클라우드플레어 등)의 DNS 관리 화면에 그대로 넣습니다.

| 종류 | 이름(호스트) | 값 |
|---|---|---|
| MX | `send` | `feedback-smtp.ap-northeast-1.amazonses.com` (우선순위 10) |
| TXT | `send` | `v=spf1 include:amazonses.com ~all` |
| TXT | `resend._domainkey` | 화면에 나오는 긴 문자열 그대로 |

넣고 **Verify** 를 누릅니다. 보통 몇 분, 늦어도 한 시간 안에 초록불이 됩니다.
정확한 값은 Resend 화면에 나오는 것을 쓰세요 — 지역에 따라 조금씩 다릅니다.

> 도메인 없이 먼저 시험만 해 보시려면 `MAIL_FROM` 에 `에피브리프 <onboarding@resend.dev>` 를 넣으면 됩니다.
> 다만 이 주소는 **가입한 본인 메일로만** 보내집니다. 실제 신청자에게는 가지 않습니다.

## 2. 열쇠 만들기

Resend → **API Keys → Create API Key** → 권한은 `Sending access` 면 충분합니다.
`re_` 로 시작하는 문자열이 한 번만 보입니다. 복사해 두세요.

## 3. 수파베이스에 넣기

수파베이스 → 프로젝트 → **Edge Functions → Secrets** → Add new secret

| 이름 | 값 | 설명 |
|---|---|---|
| `MAIL_API_KEY` | `re_…` | 2번에서 만든 열쇠 |
| `MAIL_FROM` | `에피브리프 <noreply@내도메인>` | 받는 사람 메일함에 찍힐 이름과 주소. 1번에서 인증한 도메인이어야 합니다 |
| `ADMIN_EMAIL` | 관리자 주소 | 새 신청이 들어오면 여기로 알림이 옵니다 |
| `ADMIN_KEY` | 관리 화면에서 쓰는 그 열쇠 | 결과 통보 메일을 보낼 때 확인용 |

저장하면 바로 적용됩니다. 함수를 다시 올릴 필요 없습니다.

## 4. 확인

신청 화면에서 본인 주소로 한 번 신청해 봅니다.

- 잘 되면 화면에 "**…로 접수 확인 메일을 보냈습니다**" 라고 나옵니다.
- 메일이 안 나가면 예전 문구("…로 결과를 보내 드립니다") 그대로 나옵니다.
  까닭은 수파베이스 → Edge Functions → `epibrief-mail` → **Logs** 에 적힙니다
  (`RESEND_403` 이면 보통 도메인 인증이 덜 끝난 것입니다).
- 시험 신청은 관리 화면에서 지우시면 됩니다.

## 나가는 메일 세 가지

1. **접수 확인** — 신청자에게. 신청 내용 요약 + "기다리는 동안에도 쓸 수 있습니다" 안내
2. **새 신청 알림** — 관리자에게. 관리 화면 바로가기
3. **결과 통보** — 관리 화면에서 승인·거절을 누르면 신청자에게. 거절 사유는 적은 그대로 전달됩니다

문구를 고치시려면 `index.ts` 의 `applyMail` · `adminMail` · `decisionMail` 세 곳만 보시면 됩니다.

## 다른 곳을 쓰고 싶다면

`MAIL_API_KEY` 가 `xkeysib-` 로 시작하면 **Brevo** 로 붙습니다(하루 300통 무료, 도메인 없이
주소 하나만 인증하면 됨). 함수는 열쇠 앞글자를 보고 알아서 맞춥니다.
